# 장전노트 — 나만의 주식·재무 PWA

아이폰 홈 화면에 설치해 쓰는 개인용 투자 앱이며, 같은 주소를 **PC 브라우저에서 열면 넓은 화면 레이아웃**(왼쪽 메뉴·2단 카드·오른쪽 상세 패널)으로 보입니다. 서버 비용 없이 **GitHub Actions(데이터 수집) + GitHub Pages(앱 호스팅)** 무료 티어로 동작하며, PC가 꺼져 있어도 매일 자동 갱신됩니다.

## 가장 쉬운 설치 (Claude가 대신 올리기)
1. GitHub에 빈 저장소 `jangjeon-note`(Public) 만들기
2. Claude GitHub 앱 설치: https://github.com/apps/claude/installations/select_target → 내 계정 → **Only select repositories** → `jangjeon-note` → Install
3. 저장소 **Settings → Pages → Source: GitHub Actions**
4. Claude에게 "완료"라고 말하면 파일을 올리고, 올리는 순간 자동 실행 → 10~15분 뒤 `https://아이디.github.io/jangjeon-note/` 에서 열림
5. 아이폰 Safari로 주소 열기 → 공유 → 홈 화면에 추가 (PC는 브라우저로 그냥 열면 됨)

푸시 알림은 선택 사항입니다. 나중에 아래 4단계(VAPID 키)와 6단계를 하면 켜집니다.

## 직접 설치 (처음 1회, 약 20분)

### 1. GitHub 저장소 만들기
1. github.com 가입 → 우측 상단 **+ → New repository**
2. 이름 예: `jangjeon-note`, **Public** 선택 → Create
   - Public이면 Pages·Actions가 무료·무제한입니다. Private 저장소에서 Pages를 쓰려면 유료(Pro) 플랜이 필요합니다.
   - Public이면 관심종목·설정 파일이 공개됩니다(시세 데이터뿐이며 계좌 정보는 없음).

### 2. 파일 올리기
압축을 푼 폴더 안의 내용(`.github`, `config`, `pipeline`, `tools`, `web`, `README.md`, `requirements.txt`, `.gitignore`)을 저장소에 올립니다.

- 웹으로: 저장소 화면의 **uploading an existing file** → 폴더 내용을 끌어다 놓기 → Commit
- Git으로(Windows, Git for Windows 설치 후 PowerShell):
  ```powershell
  cd C:\Users\hkjeo\Downloads\stock-pwa
  git init -b main
  git add .
  git commit -m "init"
  git remote add origin https://github.com/<아이디>/jangjeon-note.git
  git push -u origin main
  ```

### 3. 저장소 설정
- **Settings → Pages → Build and deployment → Source: GitHub Actions**
- (쓰기 권한은 워크플로 파일에 들어 있어 따로 설정하지 않아도 됩니다. 실행 로그에 403 오류가 나면 Settings → Actions → General → Workflow permissions를 Read and write로 바꾸세요.)

### 4. 푸시 알림 키 만들기 (VAPID)
PC에서:
```powershell
pip install cryptography
python tools\gen_vapid.py
```
출력된 값을 **Settings → Secrets and variables → Actions** 에 등록합니다.

| 위치 | 이름 | 값 |
|---|---|---|
| Secrets | `VAPID_PRIVATE_KEY` | 출력된 PRIVATE 값 (공유 금지) |
| Secrets | `VAPID_SUBJECT` | `mailto:본인이메일` |
| **Variables** 탭 | `VAPID_PUBLIC_KEY` | 출력된 PUBLIC 값 |

### 5. 첫 실행
**Actions → 장전노트 파이프라인 → Run workflow → job: all** → 첫 실행은 5년 백테스트까지 함께 돌아 10~15분, 이후 일일 실행은 3~5분.
앱 주소: `https://<아이디>.github.io/jangjeon-note/`

> 첫 실행 전에는 데모(합성) 데이터가 보이며 상단에 안내 배너가 뜹니다.

### 6. 아이폰에 설치 + 알림 연결
1. 아이폰 **Safari**로 앱 주소 열기 → 공유 버튼 → **홈 화면에 추가**
2. 홈 화면의 **장전노트** 아이콘으로 열기 (iOS 16.4 이상)
3. **알림 탭 → 알림 켜기 → 허용 → 구독 정보 복사**
4. GitHub **Secrets** 에 `PUSH_SUBSCRIPTIONS` 로 붙여넣기
   - 기기가 여러 대면 `[{...}, {...}]` 처럼 대괄호로 묶어 배열로 저장
5. Actions에서 `job: alerts` 로 한 번 실행해 수신 확인 (앱의 ‘테스트 알림’은 기기 표시 확인용)

### 6-1. PC에서 보기·알림
- PC 크롬/엣지에서 같은 주소를 열면 PC용 화면으로 보입니다. 주소창 오른쪽 **설치** 아이콘을 누르면 PC 앱처럼 창으로 띄울 수 있습니다.
- PC에서도 알림을 받으려면 PC 화면의 알림 탭에서 **알림 켜기 → 구독 정보 복사** 후, `PUSH_SUBSCRIPTIONS` 값을 `[아이폰 구독, PC 구독]` 처럼 대괄호로 묶어 저장하세요.

### 7. (선택) Claude AI 시황 요약
Secrets에 `ANTHROPIC_API_KEY` 를 추가하면 브리핑 상단에 Claude가 쓴 요약이 붙습니다. API 사용료가 별도로 발생하며, 없으면 규칙 기반 요약만 표시됩니다.

## 내 입맛대로 바꾸기 — `config/settings.yaml`
- `watchlist`: 관심종목 (알림·판정 대상)
- `universe`: 스크리닝·추천 후보 (미국 티커 / 한국 `종목코드.KS·.KQ: 한글명`). 무료 데이터 호출 제한 때문에 150개 이하 권장
- `dividend_candidates`: 배당 후보, `covered_call: true` 는 합산 비중 상한(기본 20%) 적용
- `dividend_plan.default_capital_krw`: 기본 투자금 (앱에서도 변경 가능)
- `alerts`: 급변 %, RSI 기준, 개별 가격 알림(`above`/`below`)

수정 후 커밋하면 다음 실행부터 반영됩니다. 바로 보려면 Actions에서 `job: all` 실행.

## 점수 산정 방식 (요약)
- 펀더멘털 지표는 **같은 시장(미국/한국) 안의 백분위(0~100)** 로 환산 → 한국 저PER 구조로 인한 왜곡 방지. 선행 PER은 같은 섹터가 4종목 이상이면 섹터 내 비교
- **가치**: 선행PER 55% · PEG 25% · PBR 20% / **퀄리티**: ROE 50% · 영업이익률 30% · 부채비율 20% / **상승여력**: 평균 목표가 괴리 75%(애널리스트 10명 미만이면 중립 쪽으로 축소) · 투자의견 25%
- **차트 점수**(0~100, 규칙 기반 절대점수): 추세 · 모멘텀 · 타이밍 — 아래 ‘차트 분석 방법’ 참고

| 기간 | 가중치 | 차트 게이트(미달 시 완화 표시) |
|---|---|---|
| 오늘 | 가치 25 · 퀄리티 15 · 상승여력 15 · **타이밍 30** · 추세 15 | 타이밍 ≥ 55 |
| 이번 주 | 가치 30 · 퀄리티 25 · 상승여력 15 · 모멘텀 15 · **추세 15** | 추세 ≥ 45 |
| 이번 달 | 가치 30 · 퀄리티 30 · 상승여력 15 · 이익성장 15 · 추세 10 | 추세 ≥ 40, ROE 8%↑, 애널리스트 3명↑ |

- 공통 게이트: 선행PER 양수, 가치 점수 50 이상(중앙값보다 저렴), 상승여력 ≥ 0, 데이터 커버리지 60% 이상, **역배열 하락추세 제외(가치 함정 방지)**, **섹터당 1종목**
- **5단계 판정**: 주간 점수 75↑ 강한 매수 / 60↑ 매수 / 40↑ 중립 / 25↑ 매도 / 그 외 강한 매도. 역배열 하락추세면 한 단계 하향
- **급락 성격 진단**: 일간 −4% 또는 5일 −8% 이하 종목에서 직전 스냅샷 대비 목표가 −5%↓, 선행 EPS −3%↓, 투자의견 악화 중 하나라도 있으면 *펀더멘털성*, 없고 밸류에이션 매력이 유지되면 *수급·심리성*

## 차트 분석 방법 (`pipeline/technical.py`)
추천 카드마다 **왜 싼가(펀더멘털)** 와 **왜 지금인가(차트)** 를 나눠 보여주고, 한 문장 요약·지지/저항·손절 참고가·손익비를 붙입니다. 상세 화면에는 캔들 차트(이평선·볼린저·지지/저항선, 거래량·RSI·MACD 보조창, 터치 크로스헤어)와 카테고리별 신호 체크리스트가 나옵니다.

| 영역 | 보는 것 |
|---|---|
| 이평선 20/50/120/250 | 완전 정배열 / 역배열 / 장기 정배열 속 단기 조정 / 단기 정배열 전환 / 혼조, 250일선 위·아래와 20일 기울기, 50일선 10일 기울기, 20일 이격도(≥110 과열, ≤90 침체) |
| 크로스 (최근 10거래일) | 20·50 단기, 50·120 중기, **50·250 장기 골든/데드크로스**, 주가의 250일선 돌파·이탈(5일) |
| 이평선 지지·저항 테스트 | 최근 3봉 저가가 이평선 ±1% 터치 후 종가 회복(직전 10봉 중 7봉 이상 위) = 지지 확인. 반대는 저항 |
| RSI(14) | 30↓ 과매도, 70↑ 과매수, 50↑ 강세 영역, **30 상향 돌파**, 70 하향 이탈, **상승/하락 다이버전스**(최근 60봉 스윙 저·고점 비교) |
| MACD(12,26,9) | 시그널 크로스(0선 위/아래 구분), 히스토그램 3일 연속 개선·축소 |
| ADX(14) | 25↑ 강한 추세(+DI/−DI로 방향), 20↓ 박스권 → 오실레이터 신호 비중↑ |
| 볼린저(20,2) | 하단 이탈 후 재진입, 하단 접근, 상단 돌파(추세장이면 가속, 아니면 과열), **밴드폭 6개월 하위 10% 스퀴즈** |
| 거래량 | 20일 평균 2배↑ 동반 상승/하락, 최근 20일 상승일/하락일 거래량비(매집·분산) |
| 캔들 | 망치형·상승장악형(하락 후), 하락장악형(상승 후), 장대양봉/음봉, 52주 신고가/신저가 |
| 가격대 | 최근 120봉 스윙 고·저점 + 이평선 → 가까운 지지·저항 2개씩, 손절 참고 = 1차 지지 − 0.5×ATR(12% 넘으면 2×ATR), 손익비 = 1차 저항까지 ÷ 손절폭 |

**차트 셋업 분류**: 신고가·돌파형 → 상승추세 속 눌림목 → 장기 추세 전환 초기(50·250 골든크로스/250일선 돌파) → 하락 후 반등 시도 → 변동성 수축 → 정배열 추세 지속 → 역배열 하락추세 → 박스권 → 중립 순으로 판정.
**점수**: 추세(배열·250일선 위치/기울기·ADX·장기 크로스), 모멘텀(RSI 구간·MACD·거래량·신고가), 타이밍(과매도·30 돌파·다이버전스·볼린저 재진입·이평 지지·반전 캔들, 역배열+장기선 하락 시 ‘떨어지는 칼날’ 감점). 종합 = 추세 40 + 모멘텀 30 + 타이밍 30.

추천 성과 추적 화면에서 **셋업별 평균 수익률·플러스 비율**이 쌓이므로, 몇 달 뒤 어떤 셋업이 실제로 잘 맞는지 확인해 가중치를 조정할 수 있습니다. 이평선 기간은 `technical.ma`에서 바꿀 수 있습니다(예: 국내식 240일).

단위테스트(합성 가격 패턴으로 각 신호 검증): `pip install pytest && python -m pytest -q`

## 규칙 검증과 자가 보정 (`pipeline/backtest.py`, `pipeline/calibrate.py`)
**백테스트**: 유니버스 10년 일봉(`backtest.period`)에서 5거래일마다 표본을 잡아, 그 시점까지의 데이터만으로 차트 분석을 실행하고 다음날 시가 진입 → 5·20·60거래일 뒤 종가 청산(왕복 비용 한국 0.25%, 미국 0.05% 차감)으로 수익률을 잽니다. 같은 날·같은 시장 표본 평균 대비 **초과수익**으로 비교해 상승장 착시를 걷어내고, 표본 중첩을 보정한 t값으로 유의성을 판단합니다. 팩터 IC(점수 순위와 이후 수익률 순위의 상관)와 점수 5분위 성과도 계산합니다.
- 검증: 랜덤 데이터에서는 어떤 셋업도 유의하지 않음(미래 참조 없음), 미래 수익률을 몰래 점수로 넣으면 IC>0.5로 잡아냄(통계 정상) — `tests/test_backtest.py`
- 한계: 펀더멘털은 과거 시점 무료 자료가 없어 제외 / 현재 대형주로 과거를 보는 생존 편향(절대 수익률은 부풀려짐)

**실전 예측 기록·채점 (`pipeline/forward.py`)**: 매일 아침 전 종목의 팩터 점수와 종합점수를 `state/snapshots/날짜.json`에 저장하고, 5·20·60거래일 뒤 실제 수익률(다음날 시가 진입)로 채점합니다. 백테스트와 달리 **펀더멘털까지 포함한 실제 예측의 성적**이라 시간이 갈수록 가장 중요한 보정 근거가 됩니다. 검증 탭의 ‘예측력 추이’에서 주간 IC가 실제로 올라가는지 확인할 수 있습니다.

**자가 보정(매주, 코드 변경 없음)**: `web/data/model.json`의 숫자만 조정하고 모든 변경을 사유와 함께 검증 탭에 기록합니다.
- 실전 기록을 학습 구간과 최근 검증 구간으로 나눠, 학습 구간 근거로 새 가중치 후보를 만들고 **현재·기본·새 후보를 검증 구간 IC로 겨뤄 0.005 이상 나을 때만 교체**(기본 모델이 이기면 자동 롤백)
- 실전 기록이 쌓이기 전(오늘 추천 약 2달, 이번 주 약 3달, 이번 달 약 9달)에는 백테스트(10년)로 차트 비중만 조정
- 근거는 IC t≥2만, 기본값과 50:50 축소, 주당 가중치 ±0.05, 단일 팩터 ≤45%, 가치 ≥10%·퀄리티 ≥8%
- 셋업 가감점: 초과수익 t≥2·유효표본 30 이상일 때만, 초과수익 0.5%p ≈ 1점, 최대 ±5점, **주당 ±2점**까지만 이동. 유의성이 사라지면 서서히 0으로 복귀
- 실제 추천(지수 대비 초과수익)이 셋업별 30건 이상 쌓이면 백테스트와 섞어 반영
- 되돌리기: `web/data/model.json`을 삭제하면 기본 가중치로 돌아가고, 다음 토요일부터 다시 학습합니다. 자가 보정 자체를 끄려면 워크플로의 `10 0 * * 6` 줄을 지우세요.

## PDCA 자동 개선 루프
| 단계 | 무엇을 | 언제 |
|---|---|---|
| Plan | 이번 주 모델(가중치·셋업 가감점) 확정 | 토요일 09:10 |
| Do | 전 종목 예측 기록 + Top3 추천 | 평일 07:40 |
| Check | 추천을 5·20·60거래일 뒤 확정 채점(지수 대비 초과수익 > 0 = 적중), 기간별 승률·초과수익, 전 종목 예측력(IC) | 매일 갱신, 토요일 집계 |
| Act | 현재·기본·새 후보 비교 → IC가 0.005 이상 좋고 **승률이 5%p 넘게 떨어지지 않을 때만** 교체, 기본이 이기면 롤백 | 토요일 09:10 |
| Review | Claude 주간 점검: 실행 오류·데이터 이상 수정, 결과 분석 보고서(`web/data/pdca_review.json`), 근거가 확인된 전략 변경은 자동 반영 + 이력 기록(사용자 승인, 2026-10-16) | 토요일 오전(예약 작업) |

결과는 검증 탭 상단 ‘이번 주 PDCA’와 추천 탭 ‘예측 vs 실제’에서 확인합니다. 최적화 목표는 순위 예측력(IC)이고, 승률은 표본이 적을 때 우연에 크게 흔들려 교체를 막는 안전장치로 씁니다.

## 기업 정보 · 재무제표 · 국제 정세 (v6)
- **기업 개요**: `config/companies.yaml`에 전 종목의 한국어 이름·사업 소개·정세 노출 태그(반도체·중국 노출·수출주·방산·정유·금리 민감 등). 새 종목은 주간 자동 점검이 채웁니다.
- **한국어 링크**: 네이버페이 증권(국내는 종목코드, 해외는 네이버 코드를 실행 중 확인해 `state/naver_codes.json`에 캐시 — 확인 안 되면 네이버 검색), 네이버 뉴스, 국내 종목은 FnGuide 재무. 야후 링크는 없앴습니다.
- **실적·재무** (`pipeline/financials.py`, 관심·추천 종목): 연간/분기 손익(매출·영업이익·이익률·순이익·EPS), 재무상태(부채비율·유동비율·순현금), 현금흐름(FCF·배당·자사주), 실적 서프라이즈, 다음 발표일, 컨센서스(EPS·매출 추정치, 30·90일 전 대비 변화). ‘실적 자동 분석’은 이 숫자로만 문장을 만듭니다.
- **국제 정세** (`pipeline/geo.py`): 미중 갈등·관세·중동·러우·북한·대만·연준·환율 8개 테마를 한국어 뉴스 48시간 건수(평소 대비) × 제목 어조(고조/완화) × 시장 반응(유가·반도체지수·원달러·금리·VIX·금 5일 변화)으로 평가 → 업종·종목 영향으로 연결. 브리핑 ‘국제 정세 체크’, 추천 카드의 ⚠️/🌐 표시, 상세 ‘국제 정세 영향’. 토요일 점검이 웹 검색으로 주간 해설(`web/data/geo_weekly.json`)을 덧붙입니다.
- **새 팩터는 기록부터**: ‘이익 추정치 변화(EPS 리비전)’와 ‘국제 정세’ 점수는 매일 예측 기록에 남기되 **가중치 0**으로 시작합니다. 실전 채점에서 IC t≥2로 유효성이 확인될 때만 자가 보정이 기존 안전장치(주당 ±0.05 등) 안에서 비중을 줍니다.

## 알아둘 한계
- 데이터는 비공식 무료 소스(Yahoo Finance, `yfinance`)입니다. 지연·결측·일시 차단이 있을 수 있으며, **한국 종목은 컨센서스(목표가·애널리스트 수)가 비어 있는 경우가 많아** 점수가 가치·퀄리티 위주로 계산됩니다.
- 판정은 전일 종가 기준이라 당일 장중 이벤트는 다음 실행에 반영됩니다. 장중 알림은 30분마다 당일 진행 중인 일봉으로 계산합니다.
- 차트 분석은 확률적 경향을 정리한 규칙일 뿐이며, 지지·저항·손절 참고가는 매매 지시가 아닙니다.
- 상세 차트 파일(`web/data/charts/`)은 관심종목·추천 종목만 만들고 매일 교체합니다. 커밋 이력이 하루 수백 KB씩 쌓이므로 1년 이상 쓰면 저장소를 새로 만드는 것을 권장합니다.
- 배당 월별 금액은 **최근 12개월 배당락월 기준 추정**입니다. 실제 입금은 미국 통상 2~4주 뒤, 국내 결산배당은 이듬해 4월 전후입니다.
- 60일 이상 저장소 활동이 없으면 GitHub가 예약 실행을 멈출 수 있습니다(데이터 커밋이 매일 생기므로 보통 유지됨). 멈추면 Actions 탭에서 다시 Enable.
- 국제 정세 판정은 키워드·가격 반응 기반이라 기사 맥락(반어·전망 기사 등)을 완전히 이해하지 못합니다. 재무제표도 무료 데이터라 한국 종목 분기·컨센서스가 비는 경우가 있습니다 — 네이버 증권·DART로 확인하세요.
- 모든 결과는 정보 제공용이며 투자 권유가 아닙니다.
